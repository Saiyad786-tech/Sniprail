Questions
Does SnipRail take screenshots?

No. Keep using Win + Shift + S, PrtScn, Snipping Tool or Xbox Game Bar. SnipRail picks up every screenshot they save.

Which languages can search read?

SnipRail uses the text recognition built into Windows, so it reads the languages installed on your PC, such as English and many others.

Does it get in the way of games or videos?

No. The bubble hides itself while anything is full screen, and comes back when you're done.

Does it work on Windows 10?

Yes, on Windows 10 (version 1809 or later) and Windows 11.
